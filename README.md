## Selected Public Work

### [Fraud Risk Decision Engine](https://github.com/dannydj/fraud-risk-decision-engine)

An explainable and auditable fraud-risk decision engine for synthetic authentication and transaction events.

Version `v1.0.0` demonstrates deterministic risk scoring, explainable rule results, PostgreSQL-backed audit persistence, a lightweight hexagonal architecture, Docker Compose execution, automated testing, reproducible synthetic benchmarking, security architecture documentation, and a STRIDE-based threat model.

The project uses exclusively fictional and synthetic data and does not contain proprietary employer, client, vendor, financial institution, or customer information.

### [Full-Stack Phonebook with CI/CD](https://github.com/dannydj/fullstackopen-phonebook-cicd)

Full-stack React, Node.js, Express, and MongoDB application demonstrating automated testing, backend validation, GitHub Actions CI/CD, deployment automation, health checks, and protected pull-request workflows.

### [CI/CD Pipeline Reference](https://github.com/dannydj/fullstackopen-cicd)

Continuous integration and deployment project demonstrating ESLint, Jest, Playwright E2E testing, Webpack production builds, controlled Render deployments, automated version tagging, deployment notifications, and GitHub Actions workflows.
